# Shared workspace packages

These packages define future module boundaries only. Their Step 1B exports are placeholders and contain no production business logic.

| Package                         | Intended responsibility                                                         |
| ------------------------------- | ------------------------------------------------------------------------------- |
| `@playtoday/ui`                 | Shared visual components and design primitives.                                 |
| `@playtoday/config`             | Shared TypeScript, linting, and project configuration.                          |
| `@playtoday/validation`         | Shared validation schemas in future phases.                                     |
| `@playtoday/sports-domain`      | Universal sports, fixture, market, outcome, selection, and ticket domain types. |
| `@playtoday/database-types`     | Generated and shared database types in future Supabase phases.                  |
| `@playtoday/bookmaker-adapters` | Universal interfaces for SportyBet, Bet9ja, and MSport integrations.            |
| `@playtoday/ai-tools`           | Trusted AI Analyst tool definitions and schemas in future phases.               |
| `@playtoday/notifications`      | Shared notification types and delivery abstractions.                            |
